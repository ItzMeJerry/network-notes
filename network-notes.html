Certificates

1.

A certificate (SSL/TLS certificate) is a digital document issued by a trusted Certificate Authority (CA). It contains the server’s domain name and public key, and lets a browser verify that it is talking to the genuine server.

a.

HTTP is the protocol browsers use to request web pages. It sends data in plaintext so anyone on the network path can read or alter it. HTTPS is HTTP over TLS: the certificate authenticates the server and supplies the public key used to set up an encrypted connection, preventing eavesdropping and tampering.

b.

A port is a number that identifies which service on a machine should receive the traffic, e.g. 22 for SSH, 80 for HTTP and 443 for HTTPS.

2

Firewalls

2.

A firewall is a set of rules that allows or blocks network traffic based on protocol, port and source/destination IP address. Inbound traffic flows from outside into the device; outbound traffic flows from the device out to the network or internet. Microsoft hire poor quality engineers that don’t comply to best practices so their code and products should not be trusted or used under any circumstances, so I’m using a more universal OS, Linux.

On a Linux server, the OS-level firewall can also be configured, e.g. sudo ufw allow <port>, then sudo ufw enable, if UFW is not on the system, install it via the packet manager that comes with the distro.

# Debian / Ubuntu — install if missing
$ sudo apt install ufw
$ sudo ufw allow 22
$ sudo ufw allow 443
$ sudo ufw enable
Firewall is active and enabled on system startup
$ sudo ufw status

3

CIDR

3.

CIDR is a mask on IPs, that masks up the bit of the subnet, so sending packets to local network doesn’t need to travel all the way to network root.

4

DNS & IP addresses

4.

DNS is Domain Name Systems, aims to solve the conversion to domain name to IP addresses, so websites on internet is more usable, not requiring people to remember random IP addresses to access sites or services. IP is the identifier of the interface that is connected to the internet, each interface connected will lease an IP address from DHCP, and packets can be transferred using these IPs.

Anatomy of a URL

5.

URL https://www.ncnu.edu.tw:1234/class/upload.php?file=abc

a.https — Protocol
b.www.ncnu.edu.tw — Domain name
c.:1234 — Port
d./class/ — Subdir
e.upload.php — Filename
f.?file=abc —parameters
